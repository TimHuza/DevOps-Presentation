🏗️ IaC

📌 What is Infrastructure as Code (IaC)?

Infrastructure as Code (IaC) is the practice of managing infrastructure using code instead of manual setup.

  • Servers, networks, and databases are defined in files
  • Changes can be version-controlled (like Git)
  • Makes infrastructure repeatable and consistent
💡 Instead of clicking in a UI → you write code

⚡ Why IaC is Important

🚀Faster setup (automation)
🔁Consistency (no human errors)
📜Version control (track changes)
🧪Easy testing and rollback

💡 Essential for modern DevOps workflows

🏗️ IaC — Declarative vs Imperative

🔄 Declarative vs Imperative

🎯 Declarative:
  • You define what you want
  • Tool decides how to create it
Example: "Create a server with 2 CPUs"
🛠️ Imperative:
  • You define how to do it step by step
Example: "Log in, install dependencies, run command A, then command B..."
💡 Terraform uses declarative approach
