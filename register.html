Pipelines 🔀

Pipeline as Code allows you to version control your build process alongside your application.

warning Important
Always prefer Declarative over Scripted pipelines for better readability and validation.
Jenkinsfile (Declarative)
pipeline {
    agent any
    stages {
        stage('Build') {
            steps { sh 'npm install' }
        }
        stage('Test') {
            steps { sh 'npm test' }
        }
        stage('Deploy') {
            steps { echo 'Deploying...' }
        }
    }
}

Check API Health
import requests

def check_service(url):
    try:
        response = requests.get(url)
        if response.status_code == 200:
            print("Service Healthy")
        else:
            print(f"Warning: {response.status_code}")
    except Exception as e:
        print(f"Error: {e}")

check_service("https://api.devops.com")
