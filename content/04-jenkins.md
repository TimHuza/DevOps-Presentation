# ⚙️ Jenkins

---

## 📌 What is Jenkins?

Jenkins is an **automation server** used in DevOps to automate tasks like:
- Building code
- Testing applications
- Deploying software

💡 It helps developers deliver software faster and more reliably

---

## 🤔 Why Jenkins is Used in DevOps

- Automates repetitive tasks
- Reduces human errors
- Integrates with many tools (Git, Docker, etc.)

👉 Key Idea: **Automation = Speed + Consistency**

---

## 🏗️ Jenkins Architecture

- **Controller (Master)** → Manages jobs
- **Agent (Worker)** → Executes tasks

💡 This allows Jenkins to scale and run multiple jobs at once

---

## 🔧 Jenkins in Action

Basic flow:
1. Developer pushes code (GitHub)
2. Jenkins detects change
3. Runs build & tests
4. Deploys application

👉 This is part of CI/CD

---

## 🚀 Summary

- Jenkins automates development workflows
- Central tool in CI/CD pipelines
- Saves time and improves reliability
